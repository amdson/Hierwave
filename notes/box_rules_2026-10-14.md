# Box rules for agents (2026-10-13 session)

Several agents share this Vast box (RTX 3090 24 GB, 80 CPUs, pid cap 2304). Follow these exactly.

## Repo and git
- Work in `/workspace/hierwave_git` (branch `coloured-pass`, a real git clone). `/workspace/hierwave` is a stale rsync copy: read-only, never run from it.
- **Do not run any git command.** The orchestrator commits and pushes after each wave. Just leave your files in place.
- Don't touch files with an `astra_` or `cfast_head` prefix (another agent's).
- Only edit files for your own variant, your own `reportables/<date>_<name>/` folder, and append entries to `reportables/progress.md`. Annotate `reportables/ideas.md` only by appending below the user's text, never editing it.

## Running JAX jobs (mandatory flags)
Every python process that imports jax must be launched like this:
```
cd /workspace/hierwave_git && source /venv/main/bin/activate
export PYTHONPATH=. XLA_PYTHON_CLIENT_PREALLOCATE=false NUMBA_NUM_THREADS=1 \
       OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
       XLA_FLAGS="--xla_cpu_multi_thread_eigen=false intra_op_parallelism_threads=1" \
       JAX_COMPILATION_CACHE_DIR=/workspace/jax_cache
taskset -c <your cores> timeout <seconds> python ...
```
- `JAX_COMPILATION_CACHE_DIR` is a persistent compile cache shared by all agents: warm it, don't delete it.
- CPU-only jobs: add `JAX_PLATFORMS=cpu`.
- Run at most **2 JAX processes at a time** from your assigned cores. Check `cat /sys/fs/cgroup/pids.current` before launching; if it is above 1800, wait.
- GPU memory is shared by up to four jobs. Keep each job under ~5 GB (B ≤ 256 on ground). If you hit OOM, lower B, don't retry blindly.
- Use `nohup ... > /tmp/<yourname>_<what>.log 2>&1 &` plus `timeout` for anything over a minute, then poll the log. Never leave a process running when you finish: `pkill -f <your script>` before your final report.

## Benchmarks
- Bench command: `python -m castlegen.bench run <variant> <problem> [--seeds 2] [--budget 150]` (read `notes/bench.md` for flags and acceptance rules). Results append to `results/bench.jsonl`; `python -m castlegen.bench board` regenerates `results/board.md`.
- The GPU is shared, so wall-clock budgets are contended. Always run your variant and its cfast baseline back to back under the same conditions, and report the number of updates each achieved. Say in the report that the GPU was shared.
- Experiments last 5–10 minutes. No sweeps or long runs without a stated reason.

## Reporting
- Each agent writes `reportables/2026-10-13_<name>/report.md` (update the existing one if present) with numbers, figures in `images/`, and plain statements of failures.

- Anything outside the constitution's allowed freedoms (`notes/coloured_pass_constitution.md`) is a proposal: write it down, cite the constraint, don't build it.

## Compile cache note (added after cbig)
cpass/cfast set the JAX cache dir at import to `~/.cache/jax_*`, which overrides `JAX_COMPILATION_CACHE_DIR` for every variant except cbig. Both locations are persistent and shared by all agents on this box, so warm compiles still work; just don't delete either. Also: cbig's training clock starts after compile, so its "updates in 150 s" is not directly comparable with cfast's, whose clock includes compile (about 11 s warm).

## Killing processes (added after an agent's pkill killed another agent's run)
Never `pkill -f python` or any pattern that could match another agent's job. Record the PIDs you launch (`$!`) and kill those PIDs only. Run at most one GPU bench at a time per agent; the GPU is shared by about five jobs and a cold compile under contention can eat a whole 150 s budget, so always warm the compile (a 30 s smoke run of the same shape) before a bench.

1. **Dimers pre-check (1 min):** train 60 s, log the three orientation fractions (script in reportables/2026-10-14_probes). If the diagonal dies, the idea does not prevent entropy collapse; stop there.
2. **Ground fast run (2-3 min):** 60-120 s training with per-level entropy, dirt fraction and line_match logged every few updates (csat.py has the instrumentation). Collapse shows by update ~200.
3. **Clamp gate (2 min):** fine cost per cell in fill-following vs own coarse contexts at L = 4 and L = 3 (scripts in reportables/2026-10-13_clamp and _cresid). cfast: 1.97 vs 0.72, 2.23 vs 0.34; probe 0.014.
4. **Full bench (300 s, 2 seeds) only when steps 1-3 pass.**
toy_modes is for estimator checks only (exact KL and mode masses).
